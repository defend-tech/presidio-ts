# @defend-tech/presidio-image-redactor

Canvas-based image redaction with optional Tesseract WASM OCR. OCR failures stop the
operation; configure worker/WASM assets and CSP before using it in Chrome MV3.

See [`docs/chrome-extension.md`](../../docs/chrome-extension.md) for MV3 bundle,
asset, CSP, and fail-closed guidance.
